Сначала проверяем файл и конфликты, затем скачиваем защитную копию текущих записей. Импорт разрешается только после подтверждения сохранения копии.

Особенности Health Tracker · личная бета

Импорт добавляет только отсутствующие записи: совпадающие пропускаются, конфликтующие идентификаторы блокируются. Полная замена архива, шифрование файлов копий и автоматическая синхронизация пока не реализованы.

Резервная копия JSON не зашифрована. Сохраняйте её отдельно, проверяйте SHA-256 перед восстановлением и не очищайте данные Safari без резервной копии. Приложение не заменяет рекомендации врача.
