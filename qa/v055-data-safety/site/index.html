Границы версии v0.2.1 SAFE UX TEST v05.5

Импорт работает без перезаписи существующих записей: новые объекты добавляются, совпадающие пропускаются, при конфликте идентификаторов импорт блокируется. Полное удаление, замена архива, зашифрованные копии и синхронизация с Mac здесь ещё не реализованы.

Это только синтетический кандидат v05.5. Фильтры журналов не изменяют сохранённые записи. Папки одного сайта не изолируют IndexedDB. Для будущих STABLE и BETA нужны разные origin. Скачивание файла не гарантирует его сохранение: убедитесь в наличии копии перед импортом. Настоящие медицинские сведения вводить нельзя.
