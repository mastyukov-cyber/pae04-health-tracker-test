Границы версии v0.2.1 SAFE UPGRADE TEST v04.1

Импорт работает без перезаписи существующих записей: новые объекты добавляются, совпадающие пропускаются, при конфликте идентификаторов импорт блокируется. Полное удаление, замена архива, зашифрованные копии и синхронизация с Mac здесь ещё не реализованы.

Это только синтетический кандидат. Папки одного сайта не изолируют IndexedDB. Для будущих STABLE и BETA нужны разные origin. Скачивание файла не гарантирует его сохранение: убедитесь в наличии копии перед импортом. Настоящие медицинские сведения вводить нельзя.
